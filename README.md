# 🎯 Bilingual Hangman Game (RU/EN) — Core Engine

Welcome! This is the core engine of my first educational Python project for my portfolio. It is a classic Hangman puzzle designed with a strong focus on clean code structure, data optimization, and multi-language support.

## 🚀 Current Features (v1.0)
* **Core Game Engine:** A stable, loop-based logic tracking player lives and hidden words.
* **Bilingual Support:** Full localization for both English and Russian languages.
* **Data Optimization:** Developed using Python `set` structures for ultra-fast alphabet and word validation.
* **Score System:** Tracks player performance in real-time (`+10` points for a correct letter, `-5` for a mistake).

## 🧠 Cambridge-level Concepts Used
1. **Python Dictionaries (`dict`):** Used to scale text configurations and hidden vocabularies seamlessly.
2. **Sets (`set`):** Applied core mathematical set operations (`alphabet - used_letters`) to ensure lightning-fast input validation.
3. **PEP 8 Standards:** The code is cleanly structured using the standard `if __name__ == "__main__":` entry point.
